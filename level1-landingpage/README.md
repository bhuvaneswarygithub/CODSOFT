# 🌸 Fragrance Shop

A clean and elegant perfume landing page designed using **HTML**, **CSS**, and **JavaScript** — fully responsive and interactive.

![Fragrance Shop Screenshot](Screenshot%202025-06-24%20203505.png)

## 💎 Features

- 💡 Stunning hero section with fragrance mist background
- 🛍️ "Add to Cart" interactive buttons (with JavaScript alert)
- 📱 Responsive navigation bar with mobile menu toggle
- 📩 Contact form with custom submit confirmation popup
- 🎬 Embedded video in the About section
- 💻 Smooth transitions and hover effects

## 🔧 Technologies Used

- HTML5  
- CSS3  
- Vanilla JavaScript  
- Font Awesome (for icons)
